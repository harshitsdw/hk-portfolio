# Harshit Kumar — Portfolio

A creative dark personal portfolio built with Next.js App Router, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Review `data/portfolio.ts` and confirm every project description, role, date and link.
2. Add or replace project screenshots. The current project cards use CSS-generated visual previews, not actual client website screenshots.
3. Add your final resume at `public/Harshit-Kumar-Resume.pdf`.
4. Add verified GitHub repository URLs in `data/portfolio.ts` where you want source links shown.
5. Confirm the LinkedIn URL and contact email.
6. Replace metadata/OG settings with your final custom domain after purchasing and configuring it.

## Deploy to Vercel

Push this folder to a GitHub repository, import it into Vercel, deploy, then add your purchased custom domain in Vercel project settings and update the DNS records at your domain provider.

The resume supplied for this portfolio lists 3+ years of experience, roles at Gashwa Technologies, Milleynium Soft and Seesoft Developers, and the projects represented in the data file. Verify all details before making the site public.
