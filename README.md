# Harshit Kumar — Elite Modern Portfolio & Production Showcase

An ultra-modern, client-ready personal portfolio & frontend engineering showcase built with **Next.js 15 App Router**, **React 19**, and **TypeScript**.

Featuring **100+ live verified production projects**, interactive category filters, direct WhatsApp and email lead funnels, and a seamless **Dark / Light Theme Switcher** — fully optimized and 100% responsive across all mobile, tablet, and desktop screens.

## 🌟 Key Architecture & Design Highlights

- **100% Fully Responsive Layout**: Tested across mobile (320px, 375px, 414px, 480px), tablets (768px, 1024px), laptops, and desktop screens with zero horizontal overflow.
- **Dual Theme Switcher**: Obsidian Dark mode (Default) & Clean Studio Light mode with `localStorage` persistence.
- **Interactive Developer Showcase**: Clickable tabs (`Harshit.tsx`, `stack.json`, `terminal.sh`) with simulated build outputs.
- **Interactive Project Filtering**: Instant category pills for All (14), Featured (7), Travel (9), CRM (2), Agency (2), Landing (1).
- **Direct Lead Capture**: 1-click WhatsApp chat (`+91 8219927740`), 1-click email copy with feedback toast, and an interactive inquiry form.

## 💻 How to Run Locally

```bash
cd harshit-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build

```bash
cd harshit-portfolio
npm run build
npm run start
```
